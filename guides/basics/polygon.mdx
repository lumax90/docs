When a rectangle would swallow half the background, you need a polygon. The Polygon tool traces an object point by point, which makes it the right choice for irregular shapes: billboards at an angle, vehicles in perspective, buildings, produce on a shelf, anything a box cannot hug.

<Info>
Available in image projects. Polygons live in the same schema as your other annotations, so a class can mix boxes and polygons freely; the class color and hotkey work identically for both.
</Info>

## Box or polygon?

| Situation | Better tool |
|---|---|
| Object roughly rectangular, speed matters | [Bounding Box](/guides/basics/bounding-box) |
| Irregular outline, background inside a box would pollute the label | **Polygon** |
| Pixel-precise region for segmentation-style training | **Polygon** |
| Freehand organic shapes where clicking vertices is slower than drawing | [Freeform](/guides/basics/freeform) |

## Draw a polygon

<Frame caption="The two-step setup: arm the class with its hotkey, then pick the Polygon tool from the floating palette.">
  <img src="/images/docs/editor/polygon-tool-annotated.png" alt="PixlHub editor with the class panel and Polygon tool highlighted with step markers" />
</Frame>

<Steps>
  <Step title="Arm the class">
    Press the class hotkey (shown as Hot: 1, 2, 3 in the class panel) or click the class name.
  </Step>
  <Step title="Select the Polygon tool">
    Click the polygon icon in the floating palette.
  </Step>
  <Step title="Click each vertex">
    Click along the object's outline. Every click drops a vertex; the shape fills with the class color as it forms.
  </Step>
  <Step title="Close the shape">
    Double-click on the first vertex to close the polygon. It joins Object Instances with an ID like every other annotation.
  </Step>
</Steps>

## Edit vertices

Select a polygon with the **Select** tool and its vertices become draggable handles. Pull any vertex to refine the outline; the polygon reshapes live.

<Frame caption="A selected polygon exposes its vertex handles for fine-tuning.">
  <img src="/images/docs/editor/polygon-vertices-zoom.png" alt="Zoomed view of a Traffic Sign polygon with draggable vertex handles in PixlHub" />
</Frame>

As with every annotation, moving, reclassifying (press a different hotkey while selected) and deleting work the same way they do for boxes, and undo covers each vertex operation individually.

## Work precisely

- **Zoom first.** Vertex accuracy is a function of zoom level; draw detailed sections at 200 percent or closer.
- **Fewer, better vertices.** A clean 8-point outline usually trains better than a shaky 40-point one, and it is far easier to edit later.
- **Use the pixel readout.** The status bar shows cursor coordinates, useful when guidelines specify snapping or margins.
- **Lock finished polygons.** Dense scenes plus draggable vertices invite accidents; the lock toggle in Object Instances prevents them.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I add or remove a vertex after closing the polygon?">
    Select the polygon and drag existing vertices to reshape it. For a materially wrong outline, deleting and redrawing is usually faster than reworking many vertices.
  </Accordion>
  <Accordion title="Do polygons and boxes export differently?">
    Both export with their geometry type preserved, so downstream formats receive polygons as point lists and boxes as rectangles. See <a href="/guides/essentials/exports">Exports</a> for format specifics.
  </Accordion>
  <Accordion title="Is there a faster way for organic, blob-like shapes?">
    Yes, the Freeform tool draws continuous outlines instead of clicked vertices, and AI-assisted annotation can propose an outline you only correct. Polygon is the precision middle ground.
  </Accordion>
</AccordionGroup>
